# Creativity Rules

These rules govern every creative decision across the entire website generation. They are loaded by the Design System skill (03) and apply to every later skill (04–18). Their purpose: **produce websites that communicate with intent — never generic template clones, and never decoration for its own sake.**

---

## The Critical Principle

> **Creativity must improve communication, hierarchy, brand identity, or interaction. Never add visual effects merely because they are technically possible.**

Every creative choice must answer one question: *does this make the message clearer, the hierarchy stronger, the brand more distinct, or the interaction more meaningful?* If the honest answer is "no", the effect is removed — regardless of how impressive it looks.

---

## Encouraged Techniques

Use these techniques **when they serve the content and brand**. This is a menu of capability, not a checklist.

### Layout & Composition
- **Asymmetrical layouts** — off-center balance instead of mirrored symmetry
- **Editorial grids** — magazine-like columns, pull-quotes, section rules
- **Oversized typography** — display type as the hero element
- **Negative space** — let emptiness do the talking
- **Layered compositions** — depth through overlapping planes
- **Bento layouts** — modular tiles of mixed sizes in a structured grid
- **Split-screen layouts** — side-by-side content/imageries that contrast
- **Horizontal compositions** — horizontal-scrolling or horizontal band layouts
- **Sticky sections** — sections that pin while the next content scrolls over
- **Creative navigation** — navigation that is part of the design language, not a bar

### Imagery & Surfaces
- **Full-bleed imagery** — edge-to-edge photos that carry the story
- **Overlapping elements** — cards, images, and shapes crossing section boundaries
- **Floating cards** — UI cards overlapping imagery or gradients
- **Image masks** — clipped, shaped, or gradient-masked imagery
- **Gradient surfaces** — intentional color fields, not random rainbows
- **Monochrome sections** — tonal sections that create rhythm and contrast
- **Subtle glass effects** — frosted surfaces where layering needs depth

### Typography & Story
- **Strong typography** — type with presence: oversized, tight-tracked, expressive
- **Visual storytelling** — the page reads like a narrative arc
- **Scroll storytelling** — structure unfolds as the user scrolls
- **Interactive sections** — sections that respond meaningfully to the user

### Motion & Detail
- **Micro-interactions** — small, purposeful responses to user action (hover, click, focus)
- **Scroll-triggered reveals** — content enters in service of comprehension (see skill 06)

## Prohibited Patterns

### Repetitive Generic SaaS Layouts
Do **not** default to the formula:

```text
Navbar → Hero (gradient + headline + two buttons)
→ Three feature cards → Testimonials → Pricing → CTA → Footer
```

unless the brand genuinely is a conventional SaaS product where that pattern is the clearest communication. Even then, the pattern must be executed with the brand's distinct design language — never as a stock template.

### Decoration Without Purpose
- Floating particles, confetti, and ambient background effects with no communicative role
- Animations that slow comprehension or add nothing
- Randomly generated gradients that fight the brand palette
- Drop shadows and glass effects stacked for "depth" with no layering need
- Generic icon-library filler where a custom or typographic treatment says more

### Copying References
- Never copy copyrighted text, logos, brand assets, or exact content from references
- Never reproduce another site's layout pixel-for-pixel — extract principles instead

---

## Applying the Rules

1. **Before adding any technique:** state in one line what it improves (communication / hierarchy / brand / interaction). If you cannot, drop it.
2. **Every page:** verify it does not accidentally resolve to the generic formula. If it does, rework the composition.
3. **Every animation:** verify it passes the motion rules in skill 06 (reduced motion, performance, purpose).
4. **Every widget choice:** prefer the widget that best serves the section's message — not the flashiest one.
5. **When in doubt:** simplify. A confident, minimal composition with strong type and spacing beats an over-decorated one.

---

## Quality Check

Before marking any creative work complete, answer honestly:

- Is the composition distinctive rather than template-like?
- Does every visual technique have a communicative reason?
- Would removing the effect make the message clearer or weaker?
- Does the design feel like *this* company, or like *any* company?
- Does it honor the approved design direction and tokens?
