# Design References (`references/`)

Put **design sample images** here — screenshots, mockups, or style samples the agent should study before designing:

```text
references/
├── hero-style-01.jpg   ← a layout/mood you like
├── card-layout.png     ← a pattern you like
└── ...                 ← any visual sample
```

Rules:

- Reference each file from `project-config.md` with a note on what to extract (see section 8 of the config template).
- The agent extracts **principles** (layout, colors, typography, mood) — it never pixel-copies a design.
- Only use images you have the right to reference. For copyrighted third-party designs, describe the style in `project-config.md` instead of storing the image.
